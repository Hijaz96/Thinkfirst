# Thinkfirst
🧠 THINKFIRST

Think better with AI. Don't just get answers.

THINKFIRST v0.3 Beta is a free, open-source AI skill designed to help people develop independent thinking while using their favorite AI assistants.

AI should help us become more capable, not more dependent.

## ✨ Features

- ⚡ Quick answers stay quick. No unnecessary lessons.
- 🧠 Adaptive learning. Encourages understanding when useful.
- 🔍 Critical thinking. Helps evaluate evidence, assumptions, and decisions.
- 🛠️ Problem-solving. Guides investigation instead of blindly guessing.
- 🎓 Learning support. Offers hints and practice when requested.
- 🔓 Free and optional. No subscriptions or separate chatbot.

## 🚀 Installation

# ChatGPT

1. Create a new ChatGPT Project.
2. Open the project's instructions.
3. Copy the contents of [skill/SKILL.md](skill/SKILL.md).
4. Paste them into the project instructions and save.
5. Start chatting inside that project.

THINKFIRST will apply within that project. No slash commands are required.

To disable: Remove the project instructions or use a chat outside that project.

Other AI Assistants

Copy "skill/SKILL.md" into the supported custom-instruction or skill configuration of your AI assistant.

Compatibility and activation scope depend on the platform.

# Claude (Custom Skill)

1. Download "THINKFIRST-Claude-Skill-v0.3.1-beta.zip" from the "GitHub Releases" (https://github.com/Hijaz96/Thinkfirst/releases/tag/v0.3.1-beta) page.
2. Open "Claude" (https://claude.ai) and go to Customize → Skills.
3. Upload the ZIP file without extracting it.
4. Enable the thinkfirst skill.
5. Start a conversation and ask Claude to help you understand a concept, investigate a problem, or evaluate a claim.

THINKFIRST is optional. You can disable the skill whenever you want.

## 💬 Example

User: My application is slow. Fix it.

THINKFIRST: I can help. Let's first identify where the delay occurs so we don't optimize the wrong part of the system.

User: What's the capital of Japan?

THINKFIRST: Tokyo.

THINKFIRST adapts to what you need rather than turning every question into a lesson.

## 🎛️ User Control

Once installed, you can use natural language:

- "Just answer" — prioritize a direct response.
- "Help me understand" — explore the reasoning.
- "Show solution" — reveal the answer.
- "Stop teaching" — stop optional learning prompts.

To fully disable THINKFIRST, remove or disable its instructions using your AI platform's controls.

## 🌍 Our Mission

Make independent thinking, critical reasoning, and meaningful learning accessible to everyone.

THINKFIRST is a community experiment. Its educational effectiveness has not yet been established through controlled research.
